# Profile Page (Dark / Light Mode)

A small desktop profile page built with Python and Tkinter. A button toggles between dark and light themes.

## Features
- Shows name, course, university, email and skills
- Dark / Light mode toggle

## Requirements
- Python 3.8+ (Tkinter comes with Python)

## Run
```bash
python profile_page.py
```

## Customise
Edit the `PROFILE` dictionary at the top of `profile_page.py` with your own details.
